Yaş Yoxlayıcı (Age Checker)

Layihə haqqında
Bu layihə Python proqramlaşdırma dilində yazılmış sadə yaş yoxlama proqramıdır. Proqram istifadəçidən adını və yaşını daxil etməsini istəyir, daxil edilən məlumatları yoxlayır və şəxsin yetkin olub-olmadığını müəyyən edir.

Funksiyalar
- İstifadəçidən ad məlumatını alır.
- Yaşın rəqəm olub-olmadığını yoxlayır.
- Yaşın 1–130 aralığında olmasını təmin edir.
- Yanlış daxil edilmiş məlumatları qəbul etmir.
- 18 və daha yuxarı yaşda olan şəxsləri yetkin hesab edir.


## İstifadə olunan texnologiyalar
- Python 3
- `input()` – istifadəçidən məlumat almaq
- `while` – dövr yaratmaq
- `if / elif / else` – şərtləri yoxlamaq
- `isdigit()` – daxil edilən məlumatın rəqəm olub-olmadığını yoxlamaq
- `int()` – məlumatı tam ədədə çevirmək


Proqramın işə salınması
python yas_yoxlamasi.py
